Kỹ năng kĩ thuật

  • - HTML
    • Mô tả chi tiết: Nắm vững Semantic HTML5, cấu trúc DOM và tối ưu hóa SEO. Thành thạo thiết kế Form, xử lý thuộc tính dữ liệu (data-attributes) và tích hợp các thư viện bên thứ ba (như Prism.js) để tối ưu hiển thị.
    • Mức độ: Advanced
  • - CSS
    • Mô tả chi tiết: Sử dụng thành thạo Flexbox, Grid để dàn trang và Responsive Design cho mọi thiết bị. Nắm vững CSS Selectors, Box Model, kỹ thuật xử lý code block (như Prism.js) và tối ưu hóa hiệu suất hiển thị giao diện.
    • Mức độ: Advanced
  • - JavaScript (JS)
    • Mô tả chi tiết: Nắm vững ES6+, xử lý bất đồng bộ (Promises, Async/Await) và thao tác DOM. Có kinh nghiệm triển khai logic phía client, xử lý API và xây dựng các thuật toán tối ưu cho hệ thống (như bộ lọc dữ liệu hoặc hệ thống gợi ý).
    • Mức độ: Intermediate
  • - React
    • Mô tả chi tiết: Thành thạo kiến trúc Component-based, React Hooks (useState, useEffect, useMemo) và quản lý State. Có khả năng tối ưu hiệu suất Rendering, xử lý Routing và tích hợp mượt mà với RESTful APIs để xây dựng các ứng dụng Single Page (SPA) phức tạp.
    • Mức độ: Intermediate
  • - Node JS
    • Mô tả chi tiết: Có khả năng xây dựng Server-side ứng dụng dựa trên kiến trúc Event-driven và Non-blocking I/O. Thành thạo framework Express, quản lý package qua NPM/Yarn và tích hợp các dịch vụ cơ sở dữ liệu (SQL, NoSQL), đảm bảo hệ thống vận hành ổn định và hiệu suất cao.
    • Mức độ: Intermediate
  • - Devops
    • Mô tả chi tiết: Thành thạo triển khai luồng CI/CD với GitHub Actions để tự động hóa kiểm thử và deploy. Có kinh nghiệm quản lý mã nguồn qua Git, đóng gói ứng dụng bằng Docker và tối ưu hóa quy trình phát triển phần mềm thông qua việc tự động hóa các tác vụ lặp lại.
    • Mức độ: Intermediate
